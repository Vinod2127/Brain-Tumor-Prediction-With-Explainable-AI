                            🎯 SUPPORTED TUMOR TYPES
════════════════════════════════════════════════════════════════════════════════

The system can classify 4 types of brain tumors:

1. 🔴 GLIOMA TUMOR
   • Most common type of brain cancer
   • Originates from glial cells
   • High severity

2. 🟠 MENINGIOMA TUMOR
   • Arises from meninges (protective membranes)
   • Medium severity
   • Generally benign but can compress brain

3. 🟢 NO TUMOR
   • Normal brain MRI
   • No tumor detected
   • Healthy indication

4. 🟣 PITUITARY TUMOR
   • Affects pituitary gland
   • Impacts hormone production
   • Medium-high severity

════════════════════════════════════════════════════════════════════════════════
                            🆘 COMMON ISSUES & SOLUTIONS
════════════════════════════════════════════════════════════════════════════════

ISSUE: Script won't execute
SOLUTION: Set execution policy
  Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

ISSUE: Port 5000 already in use
SOLUTION: Edit app.py, change port from 5000 to 5001
  Then access: http://localhost:5001

ISSUE: Model files not found
SOLUTION: Copy .keras files to project directory
  Copy-Item "..\*.keras" -Destination ".\"

ISSUE: Slow predictions
SOLUTION: Install GPU support
  pip install tensorflow[and-cuda]==2.14.0

ISSUE: Installation fails
SOLUTION: Upgrade pip first
  python -m pip install --upgrade pip
  pip install -r requirements.txt

For more issues: See QUICK_START.md or SETUP.md
