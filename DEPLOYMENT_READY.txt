                          🆘 TROUBLESHOOTING QUICK TIPS
════════════════════════════════════════════════════════════════════════════════

PROBLEM: Script won't run
SOLUTION: Set execution policy
  Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

PROBLEM: Port 5000 already in use
SOLUTION: Use different port in app.py (change 5000 to 5001)

PROBLEM: Model files not found
SOLUTION: Copy .keras files to project directory
  Copy-Item "..\efficientnetb3_best.keras" -Destination ".\"

PROBLEM: Slow predictions
SOLUTION: Install GPU support
  pip install tensorflow[and-cuda]==2.14.0

PROBLEM: Installation errors
SOLUTION: Upgrade pip first
  python -m pip install --upgrade pip

See QUICK_START.md or SETUP.md for more solutions
